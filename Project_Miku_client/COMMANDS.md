# 음성 명령 가이드

말이든 글이든 아래처럼 하면 서버(LLM)로 보내지 않고 앱이 바로 처리합니다. 예시는 모두 실제 해석기(`renderer/commands.js`)로 확인했습니다.

## 기본 규칙

- **문장 전체가 명령이어야 합니다.** 명령 앞뒤에 다른 말이 붙으면 일반 대화로 넘어갑니다.
  - 되는 말: `음악 꺼줘` / 안 되는 말: `음악 꺼진 줄 알았어`, `노래 그만 불러줘` (대화로 처리)
- 끝말(`줘`, `해줘`, `해주세요`, `해봐`, `좀` 등)은 붙여도 되고 빼도 됩니다. 띄어쓰기와 문장부호는 무시합니다.
- 캐릭터를 부르며 시작해도 됩니다: `미쿠야 음악 멈춰줘`
- 한 번에 하나씩, 짧게 말하세요. 음악이 나오는 중에는 마이크에 가깝게, 명령 앞뒤로 잠깐 쉬면 인식이 잘 됩니다.

## 음악 / 미디어 (Windows)

| 하고 싶은 것 | 이렇게 말하세요 |
|---|---|
| 다음 곡 | `다음 곡`, `다음 곡 틀어줘`, `넘겨줘`, `스킵` |
| 이전 곡 | `이전 곡`, `이전 곡으로 돌려줘` |
| 재생 | `재생`, `다시 재생해줘`, `이어서 재생`, `음악 켜줘` |
| 일시정지 | `일시정지`, `일시중지`, `음악 멈춰줘`, `음악 꺼줘`, `노래 그만`, `그만 틀어줘` |
| 지금 곡 확인 | `지금 무슨 곡이야` |

일시정지는 재생 중인 미디어를 모두 찾아 멈춥니다.

## 볼륨 / 음소거

| 하고 싶은 것 | 이렇게 말하세요 |
|---|---|
| 정확히 맞추기 | `볼륨 50으로 해줘`, `볼륨 최대`, `볼륨 최소`, `볼륨 반으로` |
| 올리기 / 내리기 | `볼륨 올려`, `볼륨 20 올려줘`, `소리 줄여`, `소리 조금 줄여줘`, `음악 소리 줄여줘` |
| 지금 볼륨 | `볼륨 몇이야` |
| 음소거 | `음소거` |
| 음소거 해제 | `음소거 해제`, `음소거 풀어줘`, `소리 다시 켜줘` |

`소리 켜줘`는 음소거 해제이고, 음악을 틀려면 `음악 켜줘` / `재생`이라고 하세요.

## 음악 예약

- `음악 30분 뒤에 꺼줘`, `10분 뒤에 노래 틀어줘`, `밤 11시에 음악 꺼줘`
- 취소: `음악 예약 취소`

## 일정 / 알림

문장 끝이 `알려줘` / `깨워줘` / `알림`이고 시각이 있어야 합니다.

- `30분 뒤에 빨래 널라고 알려줘`, `10분 타이머`
- `내일 오전 7시에 깨워줘`
- `매일 아침 8시에 약 먹으라고 알려줘`, `평일 오전 9시에 출근 알려줘`, `매주 금요일 오후 5시에 주간보고 알려줘`
- 오전/오후를 말하지 않으면 가장 가까운 미래 시각으로 잡습니다.
- 확인: `일정 보여줘` / 취소: `알림 2번 취소`, `알림 전체 취소`

## 먼저 말 걸기

| 하고 싶은 것 | 이렇게 말하세요 |
|---|---|
| 켜기 | `먼저 말 걸어줘` |
| 간격 정해서 켜기 | `30분마다 먼저 말 걸어줘`, `먼저 말 걸기 20분마다` |
| 더 자주 (간격 절반) | `더 자주 말 걸어줘` |
| 덜 (간격 두 배) | `덜 말 걸어줘` |
| 끄기 | `먼저 말 걸지 마`, `먼저 말 걸기 꺼줘` |

## 글로만 되는 명령 (입력창)

- `/emo` : 쓸 수 있는 표정 이름 목록
- `/emo happy` : 표정 미리보기
- `/일정` : 등록된 일정 목록
